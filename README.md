# Destinasi Pelancongan Menarik di Kedah 🌾

Laman web interaktif ini menampilkan pelbagai tempat pelancongan menarik di Negeri Kedah Darul Aman. 

## 📌 Kandungan Fail:
- `index.html`: Kod lengkap Laman Web (HTML, Tailwind CSS & JavaScript).
- `README.md`: Dokumentasi dan panduan projek.

## 🚀 Cara Muat Naik ke GitHub Pages:
1. Ekstrak fail `.zip` ini.
2. Cipta repository baharu di GitHub (contohnya `destinasi-kedah`).
3. Muat naik fail `index.html` dan `README.md` ke dalam repository tersebut.
4. Pergi ke **Settings** > **Pages** > Setkan branch kepada `main` / `root` dan tekan **Save**.
5. Laman web anda sedia dilawati dalam 1-2 minit!
