# Kulim Japandi Homestay — Website 5 Halaman

## Struktur fail
- `index.html` — halaman utama, pengenalan dan sorotan homestay
- `rooms.html` — maklumat lima bilik tidur
- `location.html` — lokasi dan tarikan sekitar Kulim
- `packages.html` — pakej dan harga penginapan
- `booking.html` — FAQ dan borang tempahan
- `styles.css` — gaya reka bentuk untuk semua halaman
- `script.js` — navigasi mudah alih, FAQ dan fungsi borang tempahan WhatsApp
- Fail `.jpg` — gambar homestay dan bilik

## Cara menggunakan
1. Extract fail ZIP.
2. Pastikan semua fail HTML, CSS, JavaScript dan gambar berada dalam folder yang sama.
3. Buka `index.html` menggunakan pelayar web.
4. Gunakan menu navigasi untuk berpindah antara lima halaman.
